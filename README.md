# Планировщик

Одна страница без сборки: `index.html` + `xlsx.min.js` (чтение Excel) + иконки, `manifest.webmanifest`, `sw.js` (установка на телефон и уведомления).
Папка `notify` и `.github/workflows/notify.yml` рассылают напоминания на телефон.

## Шаг 1. Приложение на GitHub Pages

1. На github.com создайте **публичный** репозиторий `planner-app`.
2. Загрузите в него всё из этой папки, включая папки `notify` и `.github` (кроме `.claude`). Откройте репозиторий → Add file → Upload files и перетащите содержимое папки.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через минуту появится адрес `https://ВАШ-ЛОГИН.github.io/planner-app/`.

В репозитории нет ваших данных: только код.

## Шаг 2. Иконка на iPhone

1. Откройте адрес из шага 1 **в Safari** (не в Chrome).
2. Кнопка «Поделиться» → «На экран Домой» → «Добавить».
3. Дальше открывайте приложение только с этой иконки.

## Шаг 3. Общая база

1. Создайте **приватный** репозиторий `planner-data` (можно пустой, с любым файлом README).
2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token:
   - Repository access: Only select repositories → `planner-data`
   - Permissions → Repository permissions → Contents: Read and write
   - срок: 1 год. Скопируйте токен.
3. В приложении: Ещё → Настройки: вставьте токен, репозиторий `ВАШ-ЛОГИН/planner-data`, нажмите «Синхронизировать». Повторите на каждом устройстве.

Токен и ключ Claude хранятся только в браузере устройства.
Деньги (выписки, операции) по умолчанию остаются на устройстве. Включается переключателем «Синхронизировать деньги через GitHub».

## Шаг 4. Уведомления на iPhone

Нужна iOS 16.4 или новее и значок на экране «Домой» (шаг 2).

1. В приложении: Ещё → Настройки → «Уведомления на телефоне» → «Создать ключи». Появится **секретный ключ**: скопируйте его (он показывается один раз).
2. В репозитории `planner-app`: Settings → Secrets and variables → Actions → New repository secret. Создайте три секрета:
   - `VAPID_PRIVATE`: секретный ключ из пункта 1;
   - `DATA_TOKEN`: тот же токен, что в шаге 3;
   - `DATA_REPO`: `ВАШ-ЛОГИН/planner-data`.
3. На iPhone в приложении (открытом с иконки): Настройки → «Включить», разрешите уведомления. Нажмите «Проверить»: должно прийти тестовое уведомление.
4. Нажмите «Синхронизировать», чтобы данные с подпиской попали в `planner-data`.
5. В репозитории `planner-app`: вкладка Actions → workflow `notify` → Run workflow. Убедитесь, что запуск зелёный. Дальше он идёт сам каждые 5 минут.

Что приходит:
- утренняя сводка (время задаётся в настройках): задач на сегодня, просрочено, ритуалов, просрочки у команды;
- напоминание в указанное время у задачи или повтора, за столько минут до срока, сколько задано в настройках (по умолчанию 10).

Чтобы напоминание пришло, у задачи должно быть время («Время напоминания» в карточке) или фраза «в 15:30» при быстром вводе.

Ограничения:
- GitHub запускает расписание с задержкой, обычно до 5–15 минут;
- репозиторий публичный, поэтому логи запусков тоже публичны; скрипт пишет в них только количества, без текстов задач;
- если в репозитории `planner-app` 60 дней нет изменений, GitHub отключает расписание. Включите его заново на вкладке Actions;
- часовой пояс берётся из настроек (по умолчанию определяется на устройстве).

## Ключ Claude

console.anthropic.com → API keys → создать ключ → вставить в настройках. Нужен для разбора голосовых входящих, категорий расходов и PDF-выписок. Без ключа работают разбор простыми правилами и Excel/CSV-выписки.

## Выписки

Excel или CSV: нужны колонки «Дата» и «Сумма» (или «Дебет» и «Кредит»), названия колонок читаются автоматически. PDF разбирает Claude.
Чтобы приложение находило платежи между вашими организациями, впишите в настройках, как каждая организация значится в выписках (название, ИНН).
